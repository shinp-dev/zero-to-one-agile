# 🎓 Agile & Scrum Learn (zero-to-one-agile)

> アジャイル開発とスクラムフレームワークの基礎を学ぶための、ドキュメント・テンプレートおよび役割別理解度チェックテストのコレクションです。

## 🚀 ディレクトリ構成

- **`reference/`**: アジャイル開発のコア概念・用語の解説資料。
  - `agile_glossary.md`: 基本用語集（スプリント、バックログ、ストーリーポイント等）。
  - `agile_glossary_detailed.md`: 実践的な詳細用語集。
  - `agile_project_flow.md`: アジャイルプロジェクト全体の流れとイベントの解説。
- **`templates/`**: アグリーメントなどのチーム開発用テンプレート。
  - `agile_team_agreement_template.md`: インセプションデッキやワーキングアグリーメント（チームの合意形成）のテンプレート。
- **`understanding_checks/`**: ロールごとの知識を測る理解度テスト（各10問）。
  - `understanding_test_dev.md`: 開発者（Developer）向けテスト。
  - `understanding_test_po.md`: プロダクトオーナー（PO）向けテスト。
  - `understanding_test_sm.md`: スクラムマスター（SM）向けテスト。

## 💡 使い方

1. **基礎理解 (Reference)**:
   `reference/` 配下のドキュメントを読み込み、アジャイルの価値観やスクラムイベントの流れを把握します。
2. **チームの合意 (Templates)**:
   プロジェクトやチーム結成時に `templates/` を使い、チームの約束事や目標（アグリーメント）を設定します。
3. **理解度測定 (Understanding Checks)**:
   スクラムの各ロール（PO, SM, Developer）についての理解度テストに取り組み、自身の役割に応じた知識を身につけます。
