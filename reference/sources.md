最終確認日: **2026-09-05**

この教材のScrum定義・用語・ルールは、次の一次資料を基準にしています。

## Scrum

- Scrum Guides — Official site  
  https://scrumguides.org/
- Scrum Guide Downloads  
  https://scrumguides.org/download.html
- Scrum Guide Revision History  
  https://scrumguides.org/revisions.html

2026-09-05時点で、Scrum Guidesは **November 2020をOfficial Current Version** としています。

教材で特に2020版へ合わせた点：

- Development Teamを独立したsub-teamとして扱わず、1つのScrum TeamにPO / SM / Developersの3accountabilitiesを置く
- self-organizingよりself-managingを用いる
- Product Goalを含む3つのcommitmentsを明示する
- Daily Scrumの固定3質問を必須としない
- Sprint BacklogをSprint中も更新される計画として扱う
- Sprint Reviewをrelease gate / PO検収会として扱わない

## 教材上のルール

User Story、Story Point、Planning Poker、Velocity、Definition of Ready、Kanban board、MVP、Inception Deck、Sprint 0などは、役立つ場合がある一方でScrum Guide必須要素ではありません。

将来Scrum Guideが改訂された場合は、このファイルの日付と公式Current Versionを最初に確認してください。
