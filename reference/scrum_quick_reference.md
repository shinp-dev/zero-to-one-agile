# Scrum Quick Reference

2026年9月時点の現行公式版 Scrum Guide 2020 に合わせた最小リファレンスです。

## Theory

- Empiricism
- Lean thinking
- Transparency
- Inspection
- Adaptation

## Values

- Commitment
- Focus
- Openness
- Respect
- Courage

## Scrum Team

- Product Owner
- Scrum Master
- Developers

Scrum Team内に階層的なsub-teamは置かず、self-managingです。

## Events

| Event | 主目的 |
|---|---|
| Sprint | 他のeventsと価値創出を包含する1か月以内の固定長event |
| Sprint Planning | Why / What / Howを計画する |
| Daily Scrum | Sprint Goalへの進捗を検査し、Sprint Backlogを適応する |
| Sprint Review | Sprintの成果と環境を検査し、次の適応を決める |
| Sprint Retrospective | 品質とeffectivenessを高める方法を計画する |

## Artifacts + Commitments

```text
Product Backlog → Product Goal
Sprint Backlog  → Sprint Goal
Increment       → Definition of Done
```

## よくある誤解

| 誤解 | 修正 |
|---|---|
| Sprint中はscope変更禁止 | Sprint Goalを危険にしない範囲でscopeを明確化・再交渉できる |
| Sprint Backlogは凍結 | 学習に応じてSprint中も更新される |
| Dailyは3質問必須 | 形式はDevelopersが選べる |
| ReviewはPOの検収会 | Scrum Teamとstakeholdersによるinspection / adaptation |
| Review後でないとrelease不可 | DoneなIncrementはSprint終了前でも届けられる |
| SMは司会者 | Scrum確立とTeam effectiveness向上へのaccountability |
| Story Pointは必須 | Scrum Guideは特定の見積単位を要求しない |
| Sprint 0は公式event | Scrum GuideにはSprint 0という特別eventはない |
