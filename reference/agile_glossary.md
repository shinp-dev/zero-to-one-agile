# アジャイル開発 用語一覧

アジャイル開発で頻出する基本的な用語の一覧です。

| 用語 | 英語表記 | 簡潔な説明 |
| :--- | :--- | :--- |
| **アジャイル** | Agile | 反復的かつ漸進的に開発を進めるソフトウェア開発手法の総称。 |
| **スクラム** | Scrum | アジャイル開発で最も広く使われているチーム主導の開発フレームワーク。 |
| **イテレーション / スプリント** | Iteration / Sprint | 開発の周期（通常1〜4週間）。この期間ごとに計画、開発、テスト、リリースを繰り返す。 |
| **プロダクトオーナー (PO)** | Product Owner | プロダクトの価値最大化とバックログの優先順位決定に責任を持つ役割。 |
| **スクラムマスター (SM)** | Scrum Master | チームの障害を取り除き、スクラムのプロセスが円滑に進むよう支援する役割。 |
| **開発チーム** | Developers | 実際にスプリント内で成果物（インクリメント）を作成するメンバー。 |
| **プロダクトバックログ** | Product Backlog | プロダクトに必要な要件や要望を優先順位順に並べたリスト。 |
| **スプリントバックログ** | Sprint Backlog | 今のスプリントで取り組むタスクをプロダクトバックログから厳選したリスト。 |
| **ユーザーストーリー** | User Story | 顧客やユーザーの視点で「誰が」「何を」「なぜ」求めているかを記述した簡潔な要件。 |
| **ストーリーポイント** | Story Points | タスクの規模や複雑さ、不確実性を相対的に表した見積もり値。 |
| **プランニングポーカー** | Planning Poker | 複数人でカードを出し合い、合意形成を図りながらストーリーポイントを見積もる手法。 |
| **ベロシティ** | Velocity | 1スプリントあたりにチームが完了できたストーリーポイントの合計値（開発速度の目安）。 |
| **インクリメント** | Increment | スプリントで完成した、動作可能で価値のあるプロダクトの成果物。 |
| **スプリントプランニング** | Sprint Planning | スプリントの最初に、そのスプリントで何を作り、どう作るかを計画するミーティング。 |
| **デイリースクラム** | Daily Scrum | 毎日進捗や課題、その日の計画を同期するために行う15分程度の短いミーティング。 |
| **スプリントレビュー** | Sprint Review | スプリントの最後に、成果物（インクリメント）を関係者にデモし、フィードバックを得る場。 |
| **レトロスペクティブ** | Retrospective | スプリントの最後に、プロセスやチームの働き方を「ふりかえり」、改善点を話し合う場。 |
| **リファインメント** | Refinement | プロダクトバックログの詳細化、見積もり、優先順位の整理を行う継続的な活動。 |
| **バーンダウンチャート** | Burndown Chart | スプリント内の残タスク量と残り時間の推移を可視化したグラフ。 |
| **MVP** | Minimum Viable Product | 顧客に価値を提供できる最小限の機能を持つ製品。 |
| **インセプションデッキ** | Inception Deck | プロジェクトの目的、背景、方向性などを関係者全員で合意・共有するためのドキュメント。 |
| **かんばん** | Kanban | タスクのステータス（ToDo、進行中、完了など）をカードで視覚的に管理するボード。 |
